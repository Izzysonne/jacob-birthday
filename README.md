# Jacob Birthday Surprise 🎁

This is a mobile-first birthday quiz website.

## Files
- `index.html` — page structure and text
- `style.css` — design
- `script.js` — quiz logic and gift selection

## Before publishing
Open `index.html` and change:
- `[Husband's Name]`
- any quiz questions/answers in `script.js`
- spa/dinner wording if needed
- voucher codes if you want different ones

## Publish with GitHub Pages
1. Create a GitHub repository, e.g. `jacob-birthday`.
2. Upload `index.html`, `style.css`, and `script.js`.
3. In GitHub: Settings → Pages.
4. Under "Build and deployment", choose "Deploy from a branch".
5. Choose the `main` branch and `/ (root)`.
6. Save.
7. GitHub will provide the public website link.

Do not put private information, passwords, phone numbers or addresses in the files.
